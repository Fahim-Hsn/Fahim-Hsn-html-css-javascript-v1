# Foodie (MealFinder)

MealFinder lets you search meals by country. Type a country name, click **Search**, and see all meals with images and names.

## Features

- Search meals by country  
- Shows images and names of all meals  
- Handles “No food found” and network errors  
- Responsive, clean design

## Tech

- HTML, CSS, JavaScript (Fetch API)
- [TheMealDB API](https://www.themealdb.com/api.php)

## Usage

1. Open `index.html` in your browser  
2. Enter a country name  
3. Click **Search** to view meals
